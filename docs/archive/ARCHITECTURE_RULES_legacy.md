# Архитектурные правила «Эра / Сфера»

- `MainActivity.kt` не раздуваем. Новую логику выносим в отдельные классы или модули.
- Код приложения и пользовательские данные разделяем.
- Git является источником истины для исходного кода.
- RAW, долговременная память, заметки, настройки Сферы и другое пользовательское состояние в будущем переносим единым пакетом.
- Android permissions, Termux/Debian/Codex, battery exclusions и другие настройки устройства восстанавливаются отдельно.
- Важную архитектуру не привязываем к TECNO/HiOS, конкретному телефону или случайным абсолютным путям.
- Каждую новую подсистему проектируем с вопросом: «переживёт ли она замену телефона?»
- Механизм Export/Import Era будет реализован позже и проверен на чистой установке до миграции на Pixel.
- API-ключи, секреты и локальные приватные данные никогда не коммитим.
- Стабильную рабочую версию и экспериментальные функции в дальнейшем разделяем через Git-ветки и/или отдельную Lab-сборку.
