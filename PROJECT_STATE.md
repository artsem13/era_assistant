# ЭРА — паспорт текущего состояния

Дата: 2026-08-01

## Цель проекта

Эра — системный Android-ассистент, который со временем должен стать общей точкой взаимодействия с ИИ и инструментами пользователя.

Основная идея:
пользователь → Эра → ИИ / локальные инструменты / приложения → действие → результат.

Проект разрабатывается непосредственно на Android-смартфоне.

---

## Устройство и среда

- Android 16
- HiOS 16.2
- Разработкав Android IDE
- Kotlin
- Package: com.era.assistant
- Gradle 6.1.1

---

## Что уже работает

### ChatGPT

Эра умеет:

- запускать официальное приложение ChatGPT;
- передавать текст через Android ACTION_SEND;
- использовать AccessibilityService;
- находить кнопку отправки ChatGPT;
- автоматически отправлять переданный текст.

Этот механизм экспериментальный и зависит от интерфейса ChatGPT.

---

## AccessibilityService

Создан:

EraAccessibilityService

Используется для взаимодействия с интерфейсом других приложений.

Подтверждён автоматический клик по кнопке отправки ChatGPT.

## Системный Android Assistant

Эра зарегистрирована как системный цифровой помощник.

Android показывает Эру в списке:

Настройки → Цифровой помощник по умолчанию.

Эру удалось выбрать помощником по умолчанию.

Создан:

EraVoiceInteractionService

Подтверждено событие:

onReady

Это означает, что Android действительно запускает VoiceInteractionService Эры.

## Эксперимент с заблокированным экраном

Цель:

понять, может ли Эра получать системный вызов ассистента при заблокированном телефоне.

Результат на 2026-08-01:

- Эра выбрана системным помощником;
- VoiceInteractionService запускается;
- onReady подтверждён логом;
- при вызове помощника на заблокированном устройстве появляется экран ввода графического ключа;
- onLaunchVoiceAssistFromKeyguard пока НЕ подтверждён.

Последний диагностический лог:

event=onReady
screenInteractive=true
deviceLocked=false
keyguardLocked=false

Следующая задача:

исследовать границу Android/HiOS Keyguard → VoiceInteractionService и выяснить, возможно ли вызвать Эру до разблокировки устройства.

## Будущая архитектура

Планируемая схема:

Эра
↓
ИИ
↓
контролируемый слой разрешений
↓
инструменты

Возможные инструменты:

- Termux
- Python
- TouchDesigner
- Unreal Engine
- Ableton
- OSC
- MIDI
- Android-приложения

ИИ не должен получать неограниченный доступ к системным инструментам.

Действия должны проходить через ограничения и разрешения Эры.
